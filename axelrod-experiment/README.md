# 重复囚徒困境锦标赛 · Axelrod 实验复现

一个 React 单页应用，用可视化方式复现罗伯特·阿克塞尔罗德 1980 年的计算机锦标赛：
让一群策略两两相遇两百个回合，看谁的总分最高。

**在线访问：** https://nomagicln.github.io/thinking-lab/

**本地运行：**

```bash
npm install
npm run dev          # 开发服务器
npm run build        # 产出静态站点到 dist/
npm run preview      # 预览构建产物
```

---

## 一、被复现的那个实验

1980 年，阿克塞尔罗德向博弈论研究者征集「重复囚徒困境」的参赛程序，一共收到 14 份投稿。
他让每一份程序与其余每一份各打 200 个回合（不含自我对局），把每场得分累加后排名。

单次博弈的收益表（本实验的默认数值）：

| 我 ＼ 对方 | 对方合作 | 对方背叛 |
|---|---|---|
| **我合作** | R = 3 / 3 | S = 0 / 5 |
| **我背叛** | T = 5 / 0 | P = 1 / 1 |

囚徒困境要求 **T > R > P > S** 且 **2R > T + S**：单次出手背叛永远是划算的，
但两个人都背叛的结果（1 分）远差于两个人都合作（3 分）。

**结果：最简单的那份程序赢了。** 是 Anatol Rapoport 提交的「一报还一报」（Tit for Tat）——
首轮合作，此后原样奉还对方上一轮的动作。它平均得 504.5 分，而「永远背叛」排在倒数。

## 三、可以调什么

左侧控制台的所有控件都是活的，改动后自动重算（`git` 时代的手感：约 10–30 ms 一次）。

| 参数 | 默认 | 它改变了什么 |
|---|---|---|
| **收益矩阵 T / R / P / S** | 5 / 3 / 1 / 0 | 诱惑有多甜、被出卖有多痛。界面会实时校验四条囚徒困境条件，不满足就标红 |
| **每场轮数** | 200 | 未来有多长。压到 5 轮，声誉机制直接失效，冠军变成「永远背叛」 |
| **重复次数** | 5 | 每组对手反复开局取平均，抹平随机策略的运气 |
| **误操作率** | 0% | 「颤抖的手」：出手前有概率把想好的动作做反 |
| **未来阴影 w** | 固定 | 切成几何延续模式后，每轮以概率 w 继续，期望轮数 = 1/(1−w) |
| **随机种子** | axelrod-1980 | 固定种子保证结果可复现；换一个种子可以检验结论稳不稳 |
| **参赛阵容** | 经典复现 · 1980 | 6 套预设阵容，也可以逐个勾选 17 位候选策略 |
| **迭代代数 / 变异率** | 150 / 0% | 只影响生态演化一节 |

### 建议试的几个实验

1. **把误操作率调到 10%** —— 一报还一报会自己把自己拖垮。它的自博弈从 600 分掉到 481 分：
   一次手滑引发一次报复，报复又引发下一次报复，这就是「回声效应」。
   此时「悔过的一报还一报」和「巴甫洛夫」反而更稳。
2. **把轮数压到 5 轮** —— 长期声誉不再重要，冠军立刻换成「永远背叛」。
   这是「未来阴影」有多长的直接后果。
3. **把 T 从 5 调到 10** —— 背叛的诱惑变大，「永远背叛」的名次会从垫底往上爬。
4. **只留下「永远合作」和「永远背叛」两个** —— 看看无条件友善在掠夺者面前能撑多久。
5. **切到「生态演化」阵容** —— 生态里 ALLD、JOSS、RANDOM 全都会灭绝，
   而一报还一报、冷酷触发、巴甫洛夫活到最后。赢下锦标赛和活过演化是两件事。

## 四、六个可视化各自在说什么

| 章节 | 它在回答 |
|---|---|
| **01 最终排名** | 谁赢了。柱长是得分占理论天花板（R × 轮数）的比例，竖线是全池平均分；名字右侧四个小方块是阿克塞尔罗德总结的四条性质（友善 / 报复 / 宽容 / 清晰） |
| **02 对阵矩阵** | 分数是从哪来的。行 = 出手方，列 = 对手。**点任意格子，下方回放区就会播放这一对选手的逐轮交手** |
| **03 收敛曲线** | 分数是怎么攒起来的。曲线斜率就是每轮赚钱的速度；一报还一报陡而稳，永远背叛冲一下然后躺平 |
| **04 生态演化** | 把得分表变成繁殖率之后，谁能活到最后。**这不是「谁更能打」，而是「谁在人群里更活得下去」** |
| **05 多人同步回放** | 选 2~17 位参与者，让所有对手**在同一轮里同时出手**，逐轮推进整场循环赛。每条泳道一格一轮，颜色 = 该轮对多少位对手选择了合作；下方矩阵实时显示「这一轮谁对谁做了什么」 |
| **06 文献对照** | 与 1980 年原始结果并排比较，以及这份复现的边界在哪 |
| **07 策略档案** | 17 张卡片，每张摊开这个策略**被测量出来的**五项行为特质（见第四节.五） |

## 四点五、多人同步回放怎么用

第 05 节不是「两个人打架」，而是**整场循环赛的同步慢放**。

- **选人**：点参与者芯片（或直接点 01 节的排名行）增减观察对象，2 到 17 位都行。
  快捷键「前四名 / 后四名 / 全部」。
  在 02 节的对阵矩阵里点任意格子，则会立刻收窄成那一对。
- **泳道**：每位参与者一条。每一条上，一格就是一轮，颜色从朱红到玉绿，
  表示这一轮它**对多少个对手选择了合作**（全背叛 → 全合作）。
  只选两个人时，颜色就退化成干脆的红/绿，和单场回放完全等价。
  泳道按本次回放的**最终得分**从上到下排好，读起来就是一条排行榜；
  左侧的序号徽章显示的却是游标所在那一轮的**实时名次**，所以中途的反超一眼可见。
  旁边还有当前累计分、每轮均分和合作率。
- **本轮快照矩阵**：下方 K×K 的格子显示游标所在这一轮里，谁对谁出了什么。
  这是「同时出手」最直观的呈现 —— 比如默认阵容里你会看到
  一报还一报对所有人都是「合作」，唯独对猜疑的一报还一报是「背叛」。
- **同步的语义**：所有对手在同一轮里并行交手，各对各自维护历史与随机流。
  选手数 K 时，每人每轮要和 K−1 位对手过招，所以每轮共 K(K−1) 次出手。
- **数字对得上**：回放的种子派生与锦标赛逐字对齐，
  所以只选两个人时，回放出来的就是 02 节矩阵里那一对的**第一次交手**，
  逐轮动作完全一致（`src/lib/engine.test.ts` 第 3.5 节专门守着这条不变式）。
- **几何延续模式下**回放取 1/(1−w) 的期望轮数当作统一回合数 ——
  各对长度不一时无法逐轮对齐，这是有意的取舍。

## 四点六、特质是「量」出来的，不是「贴标签」

这一点值得单独说，因为它涉及一个方法论选择。

阿克塞尔罗德用四条性质总结赢家：**友善、可报复、能宽容、够清晰**。
但这四条是布尔值，按字面定义，一报还一报和坚定而公平**都是四项全满** ——
画在界面上就成了同一个样子，看不出差别。

所以这里改用**测量**：把每个策略分别放进六种处境
（对上永远合作、永远背叛、一报还一报、随机、乔斯、交替者），
再统计它在四种局面下的出手倾向，得到五个连续的 0–100% 指标。

| 轴 | 含义 | 怎么量 |
|---|---|---|
| **友善** | 从不先背叛 | 整场里有没有在对方背叛之前先出手 |
| **报复** | 被背叛会还手 | 对方上一轮背叛时，我也背叛的频率 |
| **宽容** | 对方示好就收手 | 对方上一轮合作时，我合作的频率 |
| **破局** | 双双背叛后主动示好 | 上一轮双方都背叛时，我出手合作的频率 |
| **可预测** | 行为有多好懂 | 最优「只记一轮」预测器的命中率 |

前四条中的友善 / 报复 / 宽容 / 可预测即阿克塞尔罗德的四条性质；
**「破局」是本实验补充的** —— 它衡量谁愿意先打破互相背叛的死循环，
而这正是噪音环境下能否存活的关键。

于是同一对策略终于分得开了：

| 策略 | 友善 | 报复 | 宽容 | 破局 | 可预测 |
|---|---:|---:|---:|---:|---:|
| 一报还一报 TFT | 100% | 100% | 100% | **0%** | 100% |
| 坚定而公平 FBF | 100% | 88% | 100% | **28%** | 95% |
| 宽容型 TFT GTFT | 100% | 69% | 100% | **35%** | 88% |
| 巴甫洛夫 PAV | 100% | 50% | 0% | **100%** | 100% |
| 冷酷触发 GRIM | 100% | 100% | **0%** | 0% | 100% |
| 永远合作 ALLC | 100% | **0%** | 100% | 100% | 100% |
| 永远背叛 ALLD | **0%** | 100% | **0%** | 0% | 100% |
| 随机 RAND | 22% | 49% | 49% | 52% | 51% |

几个读数值得留意：

- **一报还一报破局 0%** —— 它从不主动打破互相背叛。这正是它在 10% 噪音下
  自博弈从 600 分崩到 481 分的原因（回声效应），也是巴甫洛夫（破局 100%）
  在噪音下反超它的原因。
- **冷酷触发宽容 0%** —— 一旦被背叛永不回头，所以噪音下它最惨（自博弈只剩 295 分）。
- **永远合作破局 100%** —— 它从没背叛过，也就从没记过仇。宽容到没有底线，
  所以被试探者一场榨走近千分。
- **只有 16 种组合**，17 位策略里有且只有一对重合：悔过型 TFT 与一报还一报。
  这是**正确**的 —— 在没有误操作的世界里，两者行为完全一致，
  差别只在「自己手滑之后会不会主动认错」时才显形。
  界面上会给这种情况加注记。

测量固定在**无噪音**条件下进行（特质是策略的固有倾向），
但会跟随收益矩阵变化 —— 因为巴甫洛夫这类「赢则守、输则变」的策略
要拿收益和 R 比较才知道自己赢没赢。

## 六、这份复现的边界（请务必读一下）

这部分不是免责声明，而是这个实验最容易被误读的地方。

1. **原版程序没有公开源码。** 1980 年的 14 份投稿里，只有少数几份（Rapoport 的一报还一报、
   Joss 的乔斯等）行为被完整描述过，Nydegger、Grofman、Downing、Graaskamp 等人的程序
   至今没有可考的完整实现。所以这里是**行为近似**，不是逐字节重刻。

2. **能对上的是结构与量级，不是逐行排名。** 冠军是谁、分数在 500 附近、
   背叛者在榜尾 —— 这几点对得上。但第 6 名和第 12 名的具体归属会随阵容变化。

3. **「哪种策略最好」不是一个策略的属性，而是一个种群的属性。**
   本实验里有个很直观的例子：试探者（Prober）面对「永远合作」能榨出 **994 分**，
   面对「一报还一报」只有 **599 分**。同一个策略，两种命运，差别只取决于对手是谁。
   你把「永远合作」和「两报还一报」踢出阵容再跑一次，排名会立刻翻面。

4. **自博弈不计入排名。** 这是 1980 年的规则（每位选手不与自己对局）。
   但生态演化需要对角线，所以自博弈照常计算，只是在锦标赛排名里被排除。

5. **噪声模型是「颤抖的手」。** 每次出手前独立地以概率 ε 做反。策略只能看到
   *实际发生* 的动作，看不到对方的意图 —— 所以误操作会被当真，报复循环是真实存在的。

6. **生态演化用的是标准复制者动力学**，`x_i(t+1) = x_i(t) · f_i / f̄`。
   分数本身取的是「每轮平均收益」而不是总分：复制者动力学对正数缩放不变，
   而几何延续模式下各场长度不一，必须归一。

## 八、验证

```bash
npm run typecheck    # TypeScript 严格模式
npm test             # 69 项科学自检（vitest，纯 Node）
npm run test:e2e     # 构建后跑 49 项端到端检查（无头 Chrome over CDP）
npm run verify       # 以上全部
```

端到端检查默认打本地构建产物；也可以直接打线上站点：

```bash
node test/browser-check.cjs --url https://nomagicln.github.io/thinking-lab/
```

`npm test` 的 69 项断言全部对应可查证的博弈论结论，而不是「跑起来没报错」。例如：

- TFT 对 TFT 全 200 轮合作，各得 600 分（解析可验证）
- TFT 对 ALLD 恰好 199 分（0 + 199×1）；ALLD 得 204 分
- 冷酷触发能锁死交替者（交替者只剩 107 分），但交替者能从永远合作身上榨出 800 分
- 10% 噪音下 TFT 自博弈掉到 481 分，而宽容型 TFT 是 561 分
- TFT/ALLD 双种群演化中，TFT 最终占满 100%
- 把轮数压到 5 轮，冠军变成「永远背叛」
- 多人回放里 K=2 时与两两对局逐位一致，双人回放得分等于锦标赛矩阵中对应的那一格
- 特质测量：TFT 破局恰好 0%、坚定而公平 28%（理论 1/3）、冷酷触发宽容 0%、
  巴甫洛夫破局 100%、随机五项都在 0.5 附近
- 17 位策略产出 16 种互不相同的特质组合，唯一重合的是 tft/ctft

端到端检查覆盖渲染结果与真实交互（改参数、切阵容、切几何模式、点矩阵格子联动回放、
滚动揭示不锁死正文），并顺带把整页截图存到 `.preview.png`。
这条链路抓到过两个真 bug：切换几何延续模式时对局长度骤变导致游标越界崩溃，
以及播到底之后点「播放」没有反应。
