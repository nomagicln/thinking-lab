# 麦克斯韦妖

一只小妖守在箱子里的小门边，只放快分子往右、慢分子往左。
箱子于是自己分化出一冷一热 —— 看上去，热力学第二定律就这么被打败了。

在线：https://nomagicln.github.io/thinking-lab/maxwell-demon/

这个实验要做的不是「展示悖论」，而是**把妖的账本实时算出来**：
气体少掉的熵，够不够付它擦除记忆的那笔钱。

---

## 账本上的三行

| 项 | 含义 |
|---|---|
| **ΔS气体** | 妖把快慢分子分开，气体确实变「有序」了，这一项是**负的** |
| **ΔS擦除** | 妖每做一次判断就要记一比特，记忆满了必须擦掉。按 Landauer 原理，擦除一比特至少耗散 **kT ln2** |
| **ΔS测量** | 理想测量取 0，但你可以调大，看「测量本身也要花钱」时账本怎么变 |

```
净熵变 = ΔS气体 + ΔS擦除 + ΔS测量       第二定律要求它 ≥ 0
```

---

## 结论性的一张表

固定其它参数，只改妖的记忆容量，跑同样的 16000 步：

| 妖的记忆容量 | ΔS气体 | ΔS擦除 | 净熵变 |
|---:|---:|---:|---:|
| 2 位 | −62.6 | +285.6 | **+223.0** |
| 4 位 | −56.7 | +293.9 | **+237.2** |
| 8 位 | −61.1 | +277.3 | **+216.1** |
| 16 位 | −67.3 | +310.5 | **+243.2** |
| 32 位 | −49.6 | +288.3 | **+238.8** |
| 64 位 | −62.2 | +266.2 | **+204.0** |
| 256 位 | −48.9 | +177.4 | **+128.6** |
| **无限** | −50.2 | **0.0** | **−50.2** ← 悖论 |

分界线非常干脆：**只要记忆容量有限，净熵一律为正**；
只有容量无限时才变成负数 —— 而无限容量的记忆体在物理上不存在。
Landauer 的 kT ln2 不是修辞，它是这个思想实验唯一的出口。

## 四个区块

| 区块 | 它在回答 |
|---|---|
| **观察窗** | 箱子里发生了什么。粒子按速度上色（蓝=慢，红=快），中间的门由妖控制，开门时会亮 |
| **01 妖的账本** | 三行账 + 净熵，外加一个「气体少掉的熵 vs 妖付掉的熵」的天平 |
| **02 温差是怎么建立的** | 两侧温度从同一点出发，自己分开 |
| **03 妖的代价** | 把记忆容量扫一遍，看净熵怎么变 |

## 可以调什么

| 参数 | 说明 |
|---|---|
| 粒子数 / 初始温度 / 门高 | 箱子本身。门越大穿过的分子越多，但妖也越难挑得准 |
| 快慢阈值 | 判据：速度高于它算「快」。取初始速度分布的中位数附近时妖最有效 |
| 妖的策略 | **正经妖** / **懒妖**（判据带迟滞，开门更少、梯度更慢） / **反向妖**（快慢判断反过来，造出反向温差） / **不设妖**（对照组） |
| 记忆容量 | 从 2 位到「无限」。这是这个实验最重要的一个旋钮 |
| 每次测量的额外耗散 | 单位是 kT ln2 的倍数 |

### 建议试的

1. **把「无限记忆」开关打开** —— 净熵变负，悖论复活。这就是 1867 年那个让人睡不着觉的版本。
2. **关掉它，把容量调到 4 位或 8 位** —— 擦除的账立刻把气体赚到的秩序买了回去。
3. **策略切成「不设妖」** —— 两条温度线会一直缠在一起，说明温差确实来自妖而不是抽样涨落。
4. **切成「反向妖」** —— 温差跟着反过来了，进一步佐证是妖在起作用。
5. **把「测量的额外耗散」调到 1.0** —— 连测量都要花钱时，净熵只会更正。

## 物理约定

单位取 **k = m = h = 1**。

- 二维温度：`T = <v²> / 2`（二维每个粒子两个自由度，均分定理给 `<½mv²> = kT`）
- 初始速度按二维麦克斯韦–玻尔兹曼分布抽样：`vx, vy ~ Normal(0, √T)`
- 二维理想气体熵（Sackur–Tetrode 形式）：`S = N·[ln(2πAT/N) + 2]`，
  两侧各用自己的面积求和 —— 均匀态恰好退化成整箱熵，不引入虚假的混合熵
- `ΔS擦除 = 擦除比特数 × ln2`，`ΔS测量 = 测量次数 × 耗散系数 × ln2`

隔板当作**固体**处理：禁止跨隔板的粒子对碰撞，并把粒子夹在各自一侧。
不这么做，两半会隔着零厚度隔板交换能量，连「不设妖」的对照组都会自己长出温差。

## 内核与验证

`src/lib/engine.ts` 是纯 TypeScript，不认识 React，也不碰 DOM：

```ts
createDemon(params, box, rng)             // 建箱
stepDemon(state, params, box, dt, rng)    // 推进一步，返回账本
measureDemon(state, params, box)          // 结算当前状态
idealGasEntropy(n, area, temperature)     // 二维理想气体熵
```

36 项科学自检（`src/lib/engine.test.ts`）覆盖：正经妖确实造出温差、
不设妖的冷热比贴近 1、反向妖造出反向梯度、无限记忆下气体熵确实下降、
有限记忆下净熵不为负、能量守恒、粒子数守恒、可复现性、熵公式的单调性等。

```bash
npx vitest run maxwell-demon/src/lib/engine.test.ts
```
