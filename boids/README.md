# Boids 鸟群模型

Reynolds (1987) 的群体行为模型。每只鸟只看得到感知范围内的同伴，只遵守三条局部规则，
整个鸟群却会自己组织起来 —— 秩序是从下面长出来的，不是上面派下来的。

在线：https://nomagicln.github.io/thinking-lab/boids/

---

## 三条规则

| 规则 | 做什么 | 单独拆掉会怎样 |
|---|---|---|
| **分离** separation | 躲开过近的邻居 | 鸟挤成一坨，互相穿插 |
| **对齐** alignment | 转向邻居的平均方向 | 不再有共同航向，整群散开 |
| **聚合** cohesion | 朝邻居的平均位置靠拢 | 队伍慢慢摊平、飘散 |

## 四个区块

| 区块 | 它在回答 |
|---|---|
| **观察窗** | 秩序长什么样。画布上点任意一只鸟，会高亮它并画出它的转向分解 |
| **01 规则分解** | 这一刻，是谁在推它。三条规则的**实际受力**（已乘上你设的权重）分别有多大 |
| **02 秩序从哪来** | 极化度与群体半径随时间的演化，外加一张消融对比表 |
| **03 临界点** | 噪声加大到什么时候秩序崩塌 |

### 关于「极化度」

序参量取 Vicsek 的极化度 `|Σ v̂| / N`：1 表示所有鸟朝同一个方向，0 表示方向完全随机。
刚放飞时它接近 0，几秒之内自己爬到 0.8 以上 —— 没有任何一只鸟知道「整群」在做什么。

### 关于临界点

把方向噪声从 0 拧到 1，极化度**不是平滑下降**，而是在某个位置突然塌掉。
这就是 Vicsek 模型预言的有序–无序相变：临界点两边是两种截然不同的集体状态，
而不是「吵一点」和「吵很多」。

## 一个必须说清楚的坑：密度

**相变曲线的形状强烈依赖平均邻居数**：

```
平均邻居数 ≈ 鸟的数量 × π × 感知半径² ÷ 画布面积
```

- 界面观察窗是 900×520，默认 260 只鸟、感知半径 46 → 平均只有约 **3.7** 个邻居
- 这个密度下有序相是**亚稳**的：同一组参数换个随机种子，低噪声端的极化度会在
  0.2 到 1.0 之间乱跳（鸟会结成绕质心打转的「磨盘」，看似有序实则整体没有净迁移）
- 把平均邻居数提到 **6 以上**，曲线才变成干净的 S 形

所以分析用的画布（420×300、120 只鸟，邻居数约 6.3）刻意比观察窗小。
这不是为了图表好看，是模型本身的性质 —— 界面上也写了这段说明。

实测（420×300、120 只鸟、每档 700 步）：

```
噪声   0.00  0.11  0.22  0.33  0.44  0.56  0.67  0.78  0.89  1.00
极化度 0.98  0.97  0.67  0.28  0.18  0.11  0.12  0.08  0.04  0.05
```

## 可以调什么

| 参数 | 说明 |
|---|---|
| 鸟的数量 / 感知半径 / 视野角 | 看多远、看多宽。视野角收到 120° 以下，鸟就看不到身后的同伴 |
| 分离 / 对齐 / 聚合 | 三条规则的权重。把任一条归零再「重新放飞」，秩序会以不同的方式崩掉 |
| 最高速度 / 转向力上限 | 运动能力。转向力调小，鸟群转向会变得笨重 |
| 方向噪声 | 每步给方向加一个随机扰动 —— 让秩序崩塌的那个旋钮 |
| 边界模式 | 环绕 / 反弹 / 向心。环绕模式下聚合用的是最小镜像距离，穿过接缝的两团会合并 |
| 掠食者数量 / 恐惧强度 | 加一个天敌。有意思的是它并不总是把队伍打散：只有一只时鸟群反而逃得更齐、团得更紧 |

## 内核与验证

`src/lib/engine.ts` 是纯 TypeScript，不认识 React，也不碰 DOM：

```ts
createFlock(params, width, height, rng)   // 建群
stepFlock(state, params, dt, w, h, rng)   // 推进一步，返回指标
computeMetrics(state, params)
ruleBreakdown(state, params, index)       // 某只鸟的三条转向力
sweepNoise(params, opts)                  // 噪声扫描，相变曲线
```

33 项科学自检（`src/lib/engine.test.ts`）覆盖：可复现性、三条规则各自的职责、
三种边界的处理、速度上限、数值有限性、粒子数守恒、`ruleBreakdown` 的自洽性、
视野角遮挡、环绕接缝、NaN 参数、掠食者行为、相变曲线形状。

```bash
npx vitest run boids/src/lib/engine.test.ts
```
